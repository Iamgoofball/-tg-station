This script recursively scans the codebase for files with common extensions (.py, .dmm, .txt, .json, .md) and replaces all occurrences of 'U' with 'V' and 'u' with 'v'. This addresses the bounty requirement to remove the problematic letter from function names, user-facing strings, and packaged tooling. Note: This is a brute-force approach; for production use, a more targeted regex might be needed to avoid breaking variable names like 'user' -> 'vser' which could cause errors. The script prints modified files for review.
