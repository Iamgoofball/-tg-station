# Burj Khalifa Sounds

This directory contains custom sounds used in the Burj Khalifa map.

## Structure

- `ambient/`: Ambient sounds for different areas
- `effects/`: Sound effects for special events
- `music/`: Background music for the map

## Guidelines

1. Use appropriate sound formats
2. Follow the existing sound style and quality standards
3. Use descriptive names for sound files
4. Organize sounds logically within the directory structure
