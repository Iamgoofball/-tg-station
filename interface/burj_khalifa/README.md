# Burj Khalifa Interface

This directory contains custom interface elements specific to the Burj Khalifa map.

## Structure

- `windows/`: Custom interface windows
- `panels/`: Custom interface panels
- `controls/`: Custom interface controls

## Guidelines

1. Follow the existing interface style and design principles
2. Use descriptive names for interface elements
3. Organize interface elements logically within the directory structure
4. Ensure interface elements are responsive and user-friendly
