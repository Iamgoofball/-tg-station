This is the codebase for the /tg/station flavoured fork of SpaceStation 13.

Space Station 13 is a paranoia-laden round-based roleplaying game set against the backdrop of a nonsensical, metal death trap masquerading as a space station.

### Localization
The game is available in multiple languages, including Uzbek. To contribute translations or report issues with existing translations, please visit our [localization repository](https://github.com/tgstation/tgstation-localization).
