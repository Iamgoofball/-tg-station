# Burj Khalifa Icons

This directory contains custom icons and sprites used in the Burj Khalifa map.

## Structure

- `floor_icons/`: Icons for different floor types
- `decoration_icons/`: Icons for decorative elements
- `special_icons/`: Icons for special features

## Guidelines

1. Follow the existing icon style and format
2. Use descriptive names for icons
3. Organize icons logically within the directory structure
